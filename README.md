# FocusTube

A calm Android feed of only the creators you choose, with a notification the moment they upload.

**Download:** [himanshukhandelwal.in/focustube](https://himanshukhandelwal.in/focustube)

FocusTube is free to use, but it is **not open source**. This repository only hosts the official
release files and download statistics. Every release is signed with the same key; check the
fingerprint on the download page before installing a copy from anywhere else.
